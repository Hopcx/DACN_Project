# FE — quy tắc giao diện

## FACT — nền UI đang có

main.jsx dùng AntD ConfigProvider với primary #1677ff, borderRadius 8 và font Segoe UI; Tailwind v4 đã nạp qua Vite/CSS. Có MainLayout, AuthLayout, DashboardLayout, Button, auth pages và dashboard. Auth forms dùng HTML input/useState; dashboard stats/role hardcode. Đây là nền để phát triển, chưa có ảnh/runtime để xác nhận trải nghiệm hoặc dữ liệu thật.

REQUIRED: tái sử dụng các component/layout hiện hữu khi phù hợp; chuyển dần form sang AntD Form nếu triển khai, không viết một shell hoàn toàn song song.

PROPOSED design direction: cổng học tập/thi trực tuyến rõ nội dung, màu nền trung tính và một màu nhấn. Ant Design cung cấp control, Tailwind bố cục. Chưa có screenshot UI mới để đánh giá đẹp hơn bằng thực nghiệm.

## Design tokens

Tạo một nơi định nghĩa màu nền/text/border/status/brand, spacing theo thang 4px, radius, font-size, z-index. Dùng ConfigProvider cho token control; không sửa CSS nội bộ AntD bằng selector mong manh hoặc !important hàng loạt. Kiểm tra reset Tailwind không phá control.

Typography hỗ trợ tiếng Việt; form label rõ, placeholder không thay label. Không dùng màu làm tín hiệu duy nhất. Focus hiển thị, nút icon có accessible name, modal trả focus về nơi gọi và thao tác bàn phím được.

## Patterns màn hình

| Màn | Bố cục và trạng thái |
|---|---|
| Danh sách quản trị | Title + action chính; filter; table; pagination; loading/empty/error |
| Tạo/sửa | Group field theo nghiệp vụ; lỗi sát field; bảo toàn dữ liệu khi API lỗi |
| Ngân hàng câu hỏi | Filter môn/loại/độ khó; preview đáp án theo quyền; import riêng |
| Tạo mã đề | Pool câu hỏi và danh sách đã chọn; bộ đếm/tổng điểm luôn rõ |
| Lịch thi | List mặc định có thể dùng trên màn nhỏ; calendar là view bổ sung |
| Làm bài | Câu hỏi chính; navigator câu; countdown; trạng thái đã lưu; nút nộp ổn định |
| Kết quả | Summary điểm/trạng thái trước; chi tiết chỉ khi server cho phép |

Màn thi hạn chế animation gây phân tâm. Không đặt thao tác hủy ngay cạnh nộp mà không xác nhận. Khi offline hiển thị mất kết nối và trạng thái đáp án chưa lưu; không báo “Đã lưu” khi chỉ có local state.

## Responsive và trạng thái

Kiểm tra ví dụ 360/768/1440px, zoom 200%, nội dung tiếng Việt dài. Table rộng có vùng scroll riêng; navigator câu chuyển drawer trên màn nhỏ. Không giữ chiều cao cố định khiến nút nộp mất khỏi viewport.

Loading lần đầu có skeleton phù hợp; refetch giữ nội dung cũ và báo refresh. Empty state phân biệt chưa có dữ liệu với filter không khớp. Error có retry; 403 không hiển thị nút retry vô nghĩa.

Nghiệm thu bằng ảnh và thao tác thật trên các màn chính sau khi triển khai; tài liệu này chưa phải thiết kế UI đã được render.
